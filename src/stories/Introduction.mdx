# ReportAll — Vristo Component Library

Welcome to the **ReportAll/RW** component reference built on the [Vristo](https://angular.vristo.sbthemes.com) admin template.

This Storybook catalogs every Vristo component approved for use across ReportAll web products, along with the specific variants, overrides, and usage notes that keep our UI consistent.

---

## How this is organized

| Category       | What's inside |
|----------------|---------------|
| **Components** | Higher-level building blocks — tabs, modals, cards, accordions, etc. |
| **Elements**   | Atomic UI pieces — buttons, badges, alerts, dropdowns, avatars, and more. |
| **Forms**      | Input types, validation patterns, switches, date pickers, and editors. |
| **Datatables** | Table styles and the Order Sorting datatable pattern. |

---

## ReportAll-Specific Overrides

A few global differences from vanilla Vristo to be aware of:

- **Drop shadows removed** on Buttons, Button Groups, and Dropdowns.
- **Tables default to striped** (not plain).
- **Tabs use a green (primary) outline** instead of the Vristo default.
- **Accordions use no spacing** between items.
- **Switches are rounded with a solid background color.**
- **Avatars use the Initials variant** (not photos).
